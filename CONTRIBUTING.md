# Contributing to PADIKU

Terima kasih atas minat Anda untuk berkontribusi pada repositori **PADIKU**!

Sebagai program digitalisasi UMKM & Ekonomi Sirkular Desa Jagapura Kulon, setiap kontribusi akan sangat berdampak positif bagi kemajuan masyarakat dan pemberdayaan agribisnis lokal.

## Proses Kontribusi

1. **Fork & Clone**: Lakukan *Fork* repositori ini ke akun Anda, lalu lakukan *clone* ke komputer lokal.
2. **Branch Baru**: Buat *branch* baru dengan nama yang deskriptif mengenai perbaikan/fitur Anda (contoh: `git checkout -b fitur-baru`).
3. **Commit**: Lakukan perubahan yang diperlukan. Pastikan pesan commit Anda ringkas namun jelas (kami merekomendasikan penggunaan standar *Conventional Commits* seperti `feat:`, `fix:`, `docs:`).
4. **Push**: Dorong *branch* baru Anda ke repositori pribadi (`git push origin fitur-baru`).
5. **Pull Request**: Buka *Pull Request* (PR) di repositori utama dan deskripsikan secara detail perubahan apa yang Anda buat dan alasannya.

## Panduan Pengembangan Kode

- Proyek ini menggunakan **Next.js 16 (React 19)**, **Tailwind CSS**, dan **TypeScript**.
- Jalankan perintah `npm run lint` dan `npm run type-check` sebelum melakukan komit untuk memastikan tidak ada kesalahan standar penulisan atau tipe data.
- Usahakan untuk mempertahankan estetika desain premium (*Premium UI*) di setiap komponen.
- Mohon jangan mengubah struktur utama `src/app/layout.tsx` tanpa melakukan diskusi melalui *Issue* terlebih dahulu.

Kami sangat menantikan kontribusi terbaik dari Anda!
