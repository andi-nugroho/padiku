# Security Policy

## Supported Versions

Hanya versi terbaru yang didukung secara aktif dengan pembaruan keamanan.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Jika Anda menemukan kerentanan keamanan dalam sistem situs web PADIKU, harap laporkan masalah tersebut secepatnya secara pribadi kepada tim pengelola proyek.

Mohon **JANGAN** membuat *Issue* publik untuk masalah keamanan.

**Cara melaporkan:**
Kirimkan email secara langsung ke tim pengembang atau buat *Security Advisory* privat di repositori GitHub ini. 
Kami akan merespons laporan Anda dalam waktu 48 jam kerja dan segera merilis *patch* keamanan setelah divalidasi.
